04 / SDK
01

Dagor 6.5 RT — мгновенный старт

из коробки · без SDK

Нативные C++ модули Quirrel VM и Dagor Math, архив gamedata.vromfs.bin, четыре погоды daSkies2 и живой моддинг tanks_all_nations.blk по F5.

  • F1 — справка по управлению
  • F2 — телеметрия движка
  • F3 — каркас / F4 — погода
  • ~ — консоль разработчика
02

Gaijin daNetGame — CDN prebuilt

бинарный архив Gaijin

Скрипт SETUP_FULL_DAGOR_ENGINE.ps1 -Mode dng-prebuilt скачивает официальный dngSceneViewer.7z с CDN Gaijin и монтирует модуль steelFrontOnline.

  • application.blk + .das
  • Quirrel .nut модуль игры
  • daRg-интерфейс ангара
  • без локальной сборки
03

Полный исходный SDK — Git + Jam

сборка из исходников

Клонирует GaijinEntertainment/DagorEngine, разворачивает тулчейн make_devtools.py и собирает проект каноническим пайплайном prog/build.py + jam + vromfsPacker.

  • CLANG / MSVC toolchain
  • свои шейдеры и .blk
  • полный контроль над PBR
  • экспорт в VROMFS
