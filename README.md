# STEEL FRONT: ONLINE — PC Клиент (DirectX 11 x64 + Лаунчер + Steam + Gaijin Dagor Engine Mod)

Полноценная десктопная танковая онлайн-игра для **Windows 10 / 11 (x64)** в духе **War Thunder** — **без браузера и сайтов**, с собственным **лаунчером автозагрузки (`SteelFrontLauncher.exe`)**, нативным **3D-клиентом C++17 DirectX 11 (`bin\win64\SteelFrontGame.exe`)**, **выделенным UDP-сервером (`bin\win64\SteelFrontServer.exe`)**, поддержкой **Steam (Overlay `Shift+Tab` + SteamPipe)** и полным нативным модулем под открытый движок **Gaijin Dagor Engine (`dagor_engine_mod/`)**.

---

## 🚀 Как скачать и запустить игру на ПК (Windows 10 / 11)

### Вариант 1 — Скачать один Лаунчер (`SteelFrontLauncher.exe`, 500 КБ) как у War Thunder
1. Скачайте файл **`SteelFrontLauncher.exe`** из корня репозитория в любую папку на вашем ПК.
2. Запустите **`SteelFrontLauncher.exe`**.
3. Нажмите большую красную кнопку **«СКАЧАТЬ И ИГРАТЬ»** — лаунчер сам по HTTPS докачает актуальные `bin\win64\SteelFrontGame.exe` и `bin\win64\SteelFrontServer.exe`, проверит целостность и запустит 3D-игру!

### Вариант 2 — Скачать полный архив репозитория или запустить через Steam
1. На странице GitHub ветки `arena/2571b3b1-serbia-mod` нажмите **Code → Download ZIP**, распакуйте архив и запустите **`SteelFrontLauncher.exe`** → **«ИГРАТЬ»**.
2. **Для игры через Steam с оверлеем `Shift+Tab`:**
   - Откройте клиент **Steam** → меню **«Игры» → «Добавить стороннюю игру в мою библиотеку...»**.
   - Выберите `SteelFrontLauncher.exe` или напрямую `bin\win64\SteelFrontGame.exe`.
   - При запущенном Steam игра автоматически подхватывает `steam_appid.txt` и `steam_api64.dll` (оверлей DirectX 11 и статус в сети).
   - Для публикации собственного билда в магазин Steam используйте готовые скрипты **SteamPipe** в папке `steam_build/` (`app_build.vdf`, `depot_build_win64.vdf`, `UPLOAD_TO_STEAM.bat`).

## 🌐 Онлайн-игра с друзьями по сети (`UDP 27015`)

- **Одиночный выезд / Локальный автохост (`127.0.0.1`)**: при нажатии **«В БОЙ!»** игра автоматически поднимает встроенный авторитативный сервер с тактическими ИИ-ботами `6 на 6` (или стрелковый **Полигон**).
- **Игра по сети с друзьями (LAN / Radmin VPN / ZeroTier / белый IP)**:
  1. Хост нажимает в лаунчере кнопку **«СЕРВЕР UDP 27015»** (или запускает `bin\win64\SteelFrontServer.exe`) — консоль сервера покажет ваши локальные IPv4-адреса.
  2. Друзья вписывают ваш IP в поле **«IP ОНЛАЙН-СЕРВЕРА»** в `SteelFrontLauncher.exe` и нажимают **«ИГРАТЬ» → «В БОЙ!»**.

## 🎮 Управление

- `W / A / S / D` — Движение и разворот корпуса танка
- `Мышь` — Командный круг наведения (башня и орудие доводятся с реальной скоростью приводов)
- `C` (удерживать) — Свободный обзор камерой без поворота башни
- `ЛКМ` — Выстрел основного орудия / пуск ПТУР
- `Пробел` — Огонь из спаренного и зенитного пулемётов
- `Shift` или `ПКМ` — Снайперский прицел наводчика (`Колесо мыши` — кратность зума)
- `N` — Тепловизор (`ТВП` в прицеле)
- `R` — Замер дистанции лазерным дальномером
- `1 / 2 / 3` — Выбор типа снаряда (`ОБПС` / `КС` / `ПТУР` / `ОФС`)
- `G` — Отстрел дымовых гранат «Туча»
- `F` — Полевой ремонт повреждённых модулей
- `6` — Система пожаротушения (`ППО`)
- `TAB` — Таблица счёта игроков | `Enter` — Боевой чат | `F11` — Безрамочный / Оконный экран

## ⚙️ Структура проекта и сборка из исходников

- `SteelFrontLauncher.exe` — Нативный десктопный лаунчер Windows x64 (`engine_dx11/launcher/launcher_main.cpp`).
- `bin/win64/SteelFrontGame.exe` — Нативный игровой 3D-клиент DirectX 11 (`engine_dx11/src/`).
- `bin/win64/SteelFrontServer.exe` — Выделенный авторитативный UDP-сервер (`engine_dx11/server/server_main.cpp`).
- `engine_dx11/BUILD_WIN64.bat` и `engine_dx11/CMakeLists.txt` — Скрипты пересборки C++17 под Visual Studio 2022 / Clang.
- `steam_build/` — Конфигурации Steamworks SteamPipe (`app_build.vdf`, `depot_build_win64.vdf`, `UPLOAD_TO_STEAM.bat`).
- `dagor_engine_mod/` — Полный нативный модуль `daNetGame` (C++, DaScript `.das`, Quirrel `darg` `.nut`, `.blk`, `jamfile`, `build.py`) для официального репозитория `GaijinEntertainment/DagorEngine`.
